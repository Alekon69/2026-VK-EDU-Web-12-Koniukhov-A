# Ask Me

В ДЗ2 проект перенесён на Django: добавлены маршруты, шаблоны, представления, тестовые данные и пагинация.

## Страницы сайта

- `/` — список новых вопросов.
- `/hot/` — популярные вопросы.
- `/question/1/` — страница отдельного вопроса с ответами.
- `/tag/python/` — вопросы с выбранным тегом.
- `/ask/` — форма создания вопроса.
- `/login/` — форма входа.
- `/signup/` — форма регистрации.
- `/profile/` — настройки профиля.


## Запуск проекта локально

Команды предназначены для Linux или WSL.

**1. Создать и активировать виртуальное окружение:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

**2. Установить зависимости:**

```bash
pip install -r requirements.txt
```

**3. Создать файл настроек на основе примера:**

```bash
cp .env.example .env
```


**4. Запустить сервер:**

```bash
python manage.py runserver
```

Сайт будет доступен по адресу: http://127.0.0.1:8000/

## Запуск через Docker

Необходимо установить Docker и Docker Compose.

**1. Создать файл настроек:**

```bash
cp .env.example .env
```

**2. Собрать и запустить контейнер:**

```bash
docker compose up --build
```

Сайт будет доступен по адресу: http://localhost:8000/


Для остановки нажать `Ctrl+C`, затем выполнить:

```bash
docker compose down
```

## Особенности текущей версии

В ДЗ2 используются тестовые данные, заданные в Python-коде. Списки вопросов, ответы, теги и пагинация работают с этими данными.

Формы входа, регистрации, создания вопроса и редактирования профиля являются демонстрационными. Реальная авторизация и сохранение введённых данных пока не реализованы.

На всех страницах, кроме профиля, отображается шапка неавторизованного пользователя.

**Для просмотра страницы профиля необходимо вручную перейти по адресу `/profile/`**, например http://127.0.0.1:8000/profile/. На этой странице демонстрируется шапка авторизованного пользователя. Переход к профилю через вход в аккаунт пока не предусмотрен.
